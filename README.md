# GLO Conseils — Email Signature Assets

This repository hosts the public image assets used in the **GLO Conseils** professional email signature.

## Purpose

The PNG images are publicly accessible so email clients can display the signature correctly. Active images are stored in the [`assets/`](./assets/) directory and referenced directly by the HTML signature.

## Access

This is a public repository for viewing and downloading the signature assets. Only the repository owner, **GuillaumeLoyer**, manages updates; no external collaborators are granted write access.
